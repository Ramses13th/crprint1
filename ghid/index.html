Pornește magazinul local în 3 pași

  1. Deschide folderul CRPRINT și fă dublu clic pe Start-Demo.cmd. Nu trebuie să pornești un server separat pentru magazin.
  2. Așteaptă mesajul cu adresa http://127.0.0.1:4173/. Păstrează fereastra deschisă cât folosești site-ul.
  3. Deschide magazinul sau administrarea produselor și comenzilor. Din administrare poți modifica produsele; schimbările se salvează pe acest computer.
Dacă site-ul se deschide deja, serverul este pornit: nu mai deschide încă o fereastră. Pentru oprire, apasă Ctrl+C în fereastra serverului. La următoarea utilizare, pornește din nou Start-Demo.cmd.

Începe aici: ce faci astăzi, în ordine

  1. Deschide folderul CRPRINT pe computer. Un folder este locul în care sunt fișierele site-ului; nu trebuie să le deschizi pe fiecare.
  2. Dublu-click pe Start-Demo.cmd. Se deschide o fereastră de terminal, adică fereastra care ține serverul pornit. Păstreaz-o deschisă. Dacă Windows arată o extensie ascunsă, caută fișierul cu numele Start-Demo, de tip Windows Command Script.
  3. În bara de adrese a browserului scrie http://127.0.0.1:4173/. Această adresă funcționează pe computerul tău. Nu este crprint.ro și nu este un link pe care îl trimiți clienților.
  4. Intră în Magazin, adaugă o machetă și verifică Coșul. Folosește date fictive la exercițiul de comandă. Panoul rapid este la administrare; comenzile și mesajele apar acolo.
  5. Dublu-click pe Start-WordPress.cmd. Prima pornire poate dura câteva minute fiindcă descarcă WordPress. Nu închide terminalul. Așteaptă adresa cu portul 9400 și deschide panoul WordPress local.
  6. Exersează schimbarea unui preț în Produse și verificarea unei comenzi. În acest mediu nu se trimit emailuri externe și nu se încasează bani. Aceste protecții sunt intenționate; aspectul pentru vizitatori este cel al unui magazin normal.
  7. Abia după aceste exerciții, găsește accesul la găzduirea reală și urmează capitolul WordPress. Nu încărca baza locală cu comenzile fictive peste site-ul existent.
La sfârșitul exercițiului: ai două ferestre de terminal deschise și poți vedea atât designul rapid, cât și panoul WordPress. Ca să oprești un server, selectează fereastra lui și apasă Ctrl+C. Datele WordPress rămân pentru următoarea pornire.

Pregătește o singură fișă privată

Într-un document păstrat numai de tine, notează următoarele. Nu pune parole în acest ghid, în GitHub sau într-un document public.

  1. Domeniu: crprint.ro. Cine l-a cumpărat și când expiră? Domeniul este numele; găzduirea este computerul conectat permanent la internet care ține site-ul.
  2. Găzduire: firmă, link spre panoul clientului, emailul contului, data și costul reînnoirii. Nu știi firma? Caută factura, extrasul de plată sau întreabă persoana care a făcut site-ul.
  3. WordPress: adresa de administrare, utilizatorul administrator și metoda de recuperare a accesului. Administrator înseamnă că ai acces la Teme, Pluginuri și Setări.
  4. Email: cine găzduiește căsuța hi@crprint.ro și cum intri în ea. SMTP înseamnă serviciul care trimite emailuri din site; poate fi diferit de locul unde citești mesajele.
  5. Datele firmei: denumire legală, adresă, CUI, număr de înregistrare, regim TVA, cont bancar. Completează-le din actele reale împreună cu contabilul.
  6. Produse: prețuri confirmate, costuri, scară/dimensiuni, material, culoare, termen și drepturi pentru fișierul digital. În proiect, valorile de pornire sunt 149 lei, 49 lei și 19 lei transport; înlocuiește-le înainte de vânzare.
  7. Reclame: conturile firmei și un plafon lunar ales, de exemplu 450 lei. Acest buget este pentru afișarea reclamelor și este separat de găzduire, producție și eventuale taxe.
